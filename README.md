# MINI 4WD LAB Ver.0.8.5 PWA

## Ver.0.8.5：テクニカル複合1・2の長大化と立体交差

- テクニカル複合1を全長約831mへ拡大し、4レーンの最小カーブ半径を約19.2以上へ緩和
- テクニカル複合2を左右対称の全長約762mダブルループへ刷新し、複合1との差を明確化
- 複合2の中央交差に高さ3.25のロングブリッジを設置し、最大勾配を約6.4%に抑制
- レーン選択にかかわらず共通の走行基準線を使用し、内外レーンの速度判定を平等化

## Ver.0.8.4：サイバークロス曲率・交差高・橋脚再設計

- 赤丸箇所を含むサイバークロス全体を従来の約5倍へ拡張し、4レーンの内側でも線が折れない緩やかな曲率へ変更
- 全レーンの走行判定は共通の基準線を維持し、選択レーンによる旋回速度の有利・不利を発生させない設計
- すべての自己交差で上下差3.2以上を確保し、車両が下段コースを通過できるクリアランスへ拡大
- 橋脚を上段コースの真下へ戻し、下段コースと衝突する柱だけを自動で省く支持構造へ変更

## Ver.0.8.3：スタートレーン選択・交差支持脚修正

- スタート地点の路面へ、内側から1・2・3・4のレーン番号を表示
- テスト走行で好きなスタートレーンを選択でき、車両・記録を選択レーンへ連動
- サイバークロスを含む立体コースの支持脚を路面中央から撤去し、全レーン外側の安全位置へ移設
- 交差する別の路面とも重ならないよう、支持脚候補をコース全体に対して検査

## Ver.0.8.2：4レーン・透明ガイド壁物理

- 全コースをレーン間隔1.8のワイド4レーンへ統一し、プレイヤー車を正しいレーン中心へ配置
- 描画しない透明ガイド壁とローラーの接触を走行計算へ追加し、ローラー径・摩擦・高さ・前後幅・ステー剛性が旋回損失とコースアウトへ影響
- テクニカル複合1〜3を接線が連続する閉ループへ再構成し、連続周回を標準でONに変更
- コースラインの二重補間を廃止し、タイトコーナーで線が折れ重なる表示不良を修正
- サイバークロスの交差レイアウトは維持したまま4レーン化

## Ver.0.8.1：長大な複合コースへ刷新

- 単純なオーバル中心の形状を廃止し、多数のヘアピン、S字、折返し、立体交差を持つ専用スプラインコースへ変更
- 走行計算がコース各地点の曲率を読み、複雑なコーナーに応じて減速・コースアウト判定を行うよう変更
- テスト走行はプレイヤー車両1台のみとし、同一車両のライバル表示を撤去
- 将来の性能別ライバル3台走行に備え、レーン間隔とコース全幅を拡大
- コースビルダーのプレビューも複合レイアウトへ更新

## Ver.0.8.0：3レーン・モジュラーコース

- 3台が同時に走る3レーン表示へ拡張
- 基本、高速、バンク入りテクニカル、二重立体交差、カスタムの5コースを追加
- ストレート、カーブ、ウェーブ、スロープ、20°バンク、ジャンプ台を組み合わせるコースビルダーを追加
- スマホ縦画面では性能グラフを左スワイプで収納し、残った「▶」で再表示可能

## Ver.0.7.4：車種変更時の車両消失修正

- ナンバープレートの複数マテリアルを配列として安全に破棄
- 新しい車両の生成に成功してから旧車両をシーンから外す順序へ変更
- 共有マテリアルを保持しつつ、個別ジオメトリ・マテリアル・テクスチャを重複なく解放

## Ver.0.7.3：3D依存のローカル化と更新キャッシュ修正

- Three.js 0.170.0とOrbitControlsをアプリ内へ同梱し、外部CDN障害時にも車両を表示
- Service Workerが異なるバージョンのJavaScriptを混在させないよう、クエリを含む完全URLでキャッシュ
- Service Worker更新後に一度だけ自動再読み込みし、新旧ファイル混在による初期化停止を防止

## Ver.0.7.2：フロントローラー同軸化

- ローラー、リング、シャフト、上部スタビライザーを1つのローカル軸グループへ統合
- 上部スタビライザーに残っていた前後方向のオフセットを撤廃
- 左右ローラーの中点に加え、各ローラー内部の全パーツも同一中心へ配置

## Ver.0.7.1：峠SIM車体生成の完全同期

- 峠SIMの `createRoadrageStyleCar` と同じ座標階層・回転処理へ差し替え
- ヘッドライト、フロントグリル、ドアミラー、ホイール、ナンバープレートを元モデルと同じ配置で生成
- 完成した峠SIM車両全体だけをミニ四駆側の進行軸へ変換し、個別パーツの角度を保持
- ローラー／ステーは変換後の車体共通原点を基準に左右対称配置

## Ver.0.7.0：峠SIM 6車種・ボディカスタム

- 峠SIMのプロシージャル車両データ6台を `TYPE-A`〜`TYPE-F` として移植
- 元車両のボディ、窓、灯火、ミラー、バンパー、グリル、ホイール形状を共通モジュール化
- 前後に独立V字ステー、4ローラー、選択式ダンパーを追加（従来の長い板状ステーは廃止）
- `body-custom.html` に峠SIM `cs.html` 系統の車体形状エディタを追加（ヘッドライト4点編集／テール8×8編集を含む）
- カスタム保存データをゲーム本体の該当TYPEへ反映

## Ver.0.6.1：TYPE S再造形・テスト走行改善

- テスト走行のカウントダウンを廃止し、再生操作で即時計測開始
- 本番レース用のカウントダウンは、レースモード追加時に独立実装予定
- TYPE Sを添付写真のプロポーションを参考にしたオリジナル曲面ボディへ再造形
- 中央スパイン、左右独立カウル、黒いアンダーカット、ランプポッドを分割構築
- キャノピーレール、パネルライン、エアベント、ボディ固定ビスを追加
- TYPE Sのホイールを5本スポークのグリーン仕様、標準シャーシ／ステーを明色化
- Web Audio APIによるモーター走行音（速度・モーター特性・再生速度に連動）
- スタート、完走、コースアウトの効果音
- ヘッダーの音声ボタンでON/OFFを切り替え、設定を端末に保存
- 一時停止、停止、ガレージ復帰、画面非表示時は走行音を自動停止

## リアル寄りボディ再構築（TYPE S）

添付の斜め前方1枚の写真を参考に、TYPE S（SPEED）のボディをオリジナルの曲面3Dメッシュで再構築しました。
従来のボックス・球体を積み重ねる方法ではなく、縦断形状をつなぐロフト式の連続メッシュを作成しています。

- 細長いノーズと左右に広がるフロントカウル
- 黒い細身のキャノピーと白い一体成形風カウル
- 左右独立したフェンダー、フロントフィン、リアウイング
- 青・赤のレーシングライン、部分的な金属・樹脂表現
- ボディ軽量化の見た目変更にも対応
- TYPE P/Bは従来のデザインを維持。将来別途再構築可能

これまでのパーツ・チューニング・レース・4倍走行テンポ・コースアウト演出・試走操作・SET1〜SET3保存・消耗分析・PWAアイコンは維持しています。
