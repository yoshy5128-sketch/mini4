# MINI 4WD LAB Ver.0.4.2

Ver.0.4.1をもとにジャンプ挙動を改良しました。

- 立体コースのジャンプ中、前後の重量バランスとダンパーによって車体の前後傾斜が変化
- 着地の衝撃、姿勢角、タイヤ、ダンパー性能を組み合わせて着地成功・コースアウト判定
- 着地時に小さくバウンドする場合あり。速度損失を追加
- 走行レポートに衝撃値、姿勢角、着地結果、バウンド回数を表示
- オーバルコース、4倍の走行テンポ、NormalSET、自由視点、スマホ横画面、フルスクリーン、Wake Lock、コースアウト演出、ちらつき対策を維持
- 立体コースの記録は新モデル用の別キーで管理。保存済みセッティングは維持。

JavaScript構文チェック実施。ブラウザ実機での試走は未検証です。
