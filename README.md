# MINI 4WD LAB Ver.0.4.0

## 更新内容

- 従来のロングオーバルと、坂道・下り坂・ジャンプを備えた立体テクニカルコースを切替可能
- 立体コースは高さが連続する単一路面メッシュで描画（重複路面なし）
- 坂道での加減速、ブレーキ地上高による抵抗、ジャンプ飛距離・着地判定を簡易計算
- ジャンプ着地後に衝撃が許容範囲を超えた場合は従来のコースアウト演出
- タイム記録を平面コースと立体コースで分離
- Ver.0.3.9のランダム横転・回転演出、4倍走行テンポ、ローラー、スマホ横画面UI、全画面、Wake Lockを維持

注意：物理量は現段階ではゲーム用の暫定モデルです。実車の計測値を再現するものではありません。HTTPS環境（Vercelなど）での起動を推奨します。
