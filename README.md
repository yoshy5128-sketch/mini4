# MINI 4WD LAB Ver.0.3.0

Ver.0.2.5を元に詳細チューニングを追加しました。

- ローラー高さ：±4mm（2mm刻み）
- ローラー前後幅：±24mm（12mm刻み）
- ダンパーの前後配置：5段階
- ブレーキ地上高：0〜4mm
- 3Dモデルに位置調整を表示し、走行計算に連動
- 4倍の走行再生テンポ、ロングオーバル、自由カメラ、単一メッシュ路面を維持
- 既存のセッティングは引継ぎ、新しい計測記録は別キーで保存

`index.html` をWebサーバーで配信してください。Three.jsはCDNから読み込みます。

注意：微調整の数値はゲーム用の暫定モデルです。ジャンプ・立体コースと詳細な接地判定は未実装です。

## Ver.0.3.1 横画面スマホレイアウト修正
- スマホ横向き（画面高700px以下）では、3D表示とパーツ操作を左右58:42に分割。
- 画面幅850px以下の縦レイアウト指定よりも横向き用メディアクエリを優先。
- 右側パーツ欄は単独スクロール。ヘッダー・フッターと性能ゲージは低い画面に対応。
- 走行計算・4倍テンポ・3D描画は未変更。

## Ver.0.3.2 スマホ横画面・右ペイン省スペース化
- スマホ横画面（タッチ端末・高さ700px以下）の右ペインをコンパクトに変更。
- セクション見出し、車種選択、パーツタブ、パーツボタン、微調整、試走パネルの文字・余白を縮小。
- 細かな微調整の +/- は約28pxを維持してタップ可能なサイズを確保。
- PC表示・スマホ縦表示・走行テンポ4倍・性能計算・3D描画は変更なし。
- キャッシュ区別のためスクリプトURLを更新。

## Ver.0.3.3: スマホ全画面・画面消灯防止
- スマホでは最初のタッチ操作をトリガーに全画面表示を試みます（ブラウザの仕様により拒否される場合あり）。
- 右上の「⛶ 全画面」ボタンで切り替え、全画面中は「⛶ 解除」と表示します。ユーザーが解除したあとは自動再入場しません。
- スマホでWake Lock APIが使える場合、ゲーム表示中の自動消灯を抑制します。非表示では解放し、再表示時に再取得を試みます。
- Wake LockにはHTTPS（localhostを除く）が必要で、OS・ブラウザの制限、節電設定などにより動作しないことがあります。
- 走行テンポ4倍、左右2分割、コンパクトな右ペイン、走行計算、路面・カメラ仕様は変更していません。
