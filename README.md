# MINI 4WD LAB Ver.0.5.7 PWA

## リアル寄りボディ再構築（TYPE S）

添付の斜め前方1枚の写真を参考に、TYPE S（SPEED）のボディをオリジナルの曲面3Dメッシュで再構築しました。
従来のボックス・球体を積み重ねる方法ではなく、縦断形状をつなぐロフト式の連続メッシュを作成しています。

- 細長いノーズと左右に広がるフロントカウル
- 黒い細身のキャノピーと白い一体成形風カウル
- 左右独立したフェンダー、フロントフィン、リアウイング
- 青・赤のレーシングライン、部分的な金属・樹脂表現
- ボディ軽量化の見た目変更にも対応
- TYPE P/Bは従来のデザインを維持。将来別途再構築可能

これまでのパーツ・チューニング・レース・4倍走行テンポ・コースアウト演出・試走操作・SET1〜SET3保存・消耗分析・PWAアイコンは維持しています。
