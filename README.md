# MINI 4WD LAB Ver.0.5.3 — PWA

- 左下の視点ボタンを削除。ドラッグ/スワイプとズームは維持。
- 左側の性能・分析パネルを広げ、スマホの上下余白を削減。
- スマホ上部メニューを1行表示へ調整。
- パーツ「ステー」「軽量ボディ」を追加。カーボンステー／ボディ肉抜き／軽量ボディキット等を試験装着可能。
- 特別パーツは現在無料。将来の大会モードでは入手条件を設定する想定。
- 重量・剛性・着地安定性・空気抵抗にパーツの効果を反映。
- 装着後の見た目にもステーとボディの差異を反映。
- ユーザー指定のPWAアイコン3枚を**加工せずそのまま**使用。
- Service Worker キャッシュを0.5.3に更新。ユーザー設定・記録を維持。

## 起動
HTTPSサイト(Vercelなど)に全ファイルをそのまま配置してください。WebGLとCDNライブラリの初回取得にはネット接続が必要です。

※シミュレーション数値はゲーム内の仮設定です。
