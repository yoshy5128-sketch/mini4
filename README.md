# MINI 4WD LAB Ver.0.4.3

Ver.0.4.2をベースにした試走ループ・大会背景試作版です。

- テスト走行の「連続周回」チェックONで走行を継続します。OFFは従来どおり1周で終了します。
- 周回数、前周タイム、最速ラップを表示。最速タイムは従来のコース別記録として保存します。
- 連続走行の「停止」ボタンと走行中のループON/OFF切替に対応。
- コースアウトすればループは終了し、従来のコースアウト演出を表示します。
- 背景チェックで添付の会場画像を仮の2D背景パネルとして表示／非表示。自由視点では平面画像として見えるため、最終的には会場の3D化を検討します。
- 電池、タイヤ、パーツの消耗はまだありません。
- 4倍テンポ、両コース、NormalSET、スマホ横画面、全画面、Wake Lock、路面ちらつき対策を維持します。

ローカルでの試用はHTTPサーバー経由で起動してください。ブラウザ実機での最終検証は未実施です。
