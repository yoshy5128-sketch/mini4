# MINI 4WD LAB Ver.0.4.9 — 連続走行での消耗テスト

## 追加機能
- 試走画面に「消耗・発熱 ON」チェックを追加。OFFでは以前の一定性能で走ります。
- ONでは電池残量、タイヤ状態、モーター温度がモデル時間・走行距離に応じて変化します。
- 電池低下は最高速・加速、タイヤ摩耗はグリップと着地安定性、高温はモーター出力に影響します。
- 電池残量が0%になると連続走行を終了します。
- 状態パネルで3つの指標と累計走行距離を表示。
- 各試走開始時に新品状態に戻ります。現段階では消耗状態をセーブしません。
- 消耗ONのタイムは消耗OFFとは別のベスト記録として管理します。

## 維持
- 大会背景4面、土台色設定、立体コース、自由視点、4倍テンポ、ループ、NormalSET、コースアウト演出。

## 注意
消耗率や温度はゲーム用の仮モデルで、実車測定値ではありません。ブラウザ実機確認は未実施。
