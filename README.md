# MINI 4WD LAB Ver.0.4.4 — 大会背景・東西南北テスト

Ver.0.4.3 の機能は維持し、添付された新しい大会会場画像を、3Dコースの四方（北・南・東・西）に同じ画像を繰り返し貼る方式へ変更しました。各パネルはコース方向を向いた内壁です。プレイヤーが自由視点でカメラを回して、壁の配置・高さ・画像のつながりを確認できます。

## 表示方法

テスト走行画面の「大会背景・4方向配置（テスト）」にチェックを入れると表示。チェックを外すと非表示。ガレージでは非表示です。

## 今後の構成

本背景は大会会場の仮配置テスト専用です。今後、テストコースの背景は独立して作成する想定です。4面の角では画像の継ぎ目が見えることがあります。背景には現在、奥行きのない2D画像を使用しています。

走行テンポ4倍、ループ走行、コースアウト演出、NormalSET、スマホ横画面、Wake Lockを維持しています。

ブラウザでの実機表示は未検証です。
