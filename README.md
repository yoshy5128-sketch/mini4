# MINI 4WD LAB Ver.0.9.1 PWA

## Ver.0.9.1：ライバル車の表示修正

- 旧コース面の表示切り替えがライバル車グループまで非表示にしていた問題を修正
- 草レース開始時にライバル車グループを明示的に表示し、選択台数の全車が各レーンへ登場

## Ver.0.9.0：最大4台の草レース

- 試走画面に「マシンを追加する（草レース）」を追加し、プレイヤーを含む2～4台を選択可能
- レース周回数を1・3・5・10周から指定し、全車ゴール後に正式順位とタイムを表示
- ライバル車をプレイヤー以外の空きレーンへ1台ずつ配置し、リアルタイム順位表を追加
- プレイヤー設定を基準に、モーター・ギヤ・タイヤ・ローラー・ダンパー・電池・軽量ボディと微調整を各車で変更
- 各ライバルの実重量を再計算し、性能差を小さく補正して接戦になりやすいバランスへ調整
- 青・紫・オレンジの専用ボディカラーと異なるTYPEを各ライバルへ適用
- ライバルにも電池消耗、タイヤ摩耗、モーター発熱・寿命を適用

## Ver.0.8.10：観客席・フェンス一体化

- 独立した3Dフェンスリングを廃止し、宙に浮いて見える問題を修正
- 元画像の下端6.5%を同じ背景テクスチャ内で14%へ拡大し、青いフェンスを視認可能に調整
- 観客席からフェンス、床面まで単一円筒上で連続する構成へ変更

## Ver.0.8.9：観客席前フェンス表示

- 背景画像の下端に描かれた青いセーフティフェンス部分を専用の内周リングとして表示
- 元画像のフェンス部分だけを高さ9の帯へ拡大し、床面との境界に埋もれない見え方へ調整
- カメラの外周制限をフェンスより10内側へ変更し、近接時にもフェンスを安定表示

## Ver.0.8.8：継ぎ目なし会場背景

- 4枚の平面観客席を、内側から表示する1枚の円筒型観客席へ置き換え
- 斜め視点で平面同士の角に発生していた大きな三角形の背景欠けを解消
- カメラ位置を円形会場の内側へ制限し、全コース・全方位で背景を維持

## Ver.0.8.7：会場カメラ制限・S字明確化

- テスト走行のズームアウト上限をコース寸法に連動させ、カメラが観客席の外側へ抜ける問題を修正
- テスト走行中の横移動を止め、カメラ位置を4方向の会場壁内へ制限
- 会場床を十分に拡張し、俯瞰表示でも床面の端が露出しない構成へ変更
- テクニカル複合1を約568mへ再調整し、上下のロング区間に視認しやすい緩やかなS字を配置

## Ver.0.8.6：テクニカル複合1短縮・S字追加・複合3廃止

- テクニカル複合1を全長約831mから約613mへ短縮し、観客席内へ収まる約228×124の表示範囲へ調整
- 上下のロング区間へ曲率が連続する緩やかなS字を追加し、4レーンの最小カーブ半径約19.3以上を維持
- 内容が旧形状のままだったテクニカル複合3をコース選択肢と公開プリセットから削除
- コースビルダーの省スペース形状は内部専用データへ分離し、カスタムコース機能を維持

## Ver.0.8.5：テクニカル複合1・2の長大化と立体交差

- テクニカル複合1を全長約831mへ拡大し、4レーンの最小カーブ半径を約19.2以上へ緩和
- テクニカル複合2を左右対称の全長約762mダブルループへ刷新し、複合1との差を明確化
- 複合2の中央交差に高さ3.25のロングブリッジを設置し、最大勾配を約6.4%に抑制
- レーン選択にかかわらず共通の走行基準線を使用し、内外レーンの速度判定を平等化

## Ver.0.8.4：サイバークロス曲率・交差高・橋脚再設計

- 赤丸箇所を含むサイバークロス全体を従来の約5倍へ拡張し、4レーンの内側でも線が折れない緩やかな曲率へ変更
- 全レーンの走行判定は共通の基準線を維持し、選択レーンによる旋回速度の有利・不利を発生させない設計
- すべての自己交差で上下差3.2以上を確保し、車両が下段コースを通過できるクリアランスへ拡大
- 橋脚を上段コースの真下へ戻し、下段コースと衝突する柱だけを自動で省く支持構造へ変更

## Ver.0.8.3：スタートレーン選択・交差支持脚修正

- スタート地点の路面へ、内側から1・2・3・4のレーン番号を表示
- テスト走行で好きなスタートレーンを選択でき、車両・記録を選択レーンへ連動
- サイバークロスを含む立体コースの支持脚を路面中央から撤去し、全レーン外側の安全位置へ移設
- 交差する別の路面とも重ならないよう、支持脚候補をコース全体に対して検査

- テクニカル複合1〜3を接線が連続する閉ループへ再構成し、連続周回を標準でONに変更
- コースラインの二重補間を廃止し、タイトコーナーで線が折れ重なる表示不良を修正
- サイバークロスの交差レイアウトは維持したまま4レーン化

## Ver.0.8.1：長大な複合コースへ刷新

## リアル寄りボディ再構築（TYPE S）

添付の斜め前方1枚の写真を参考に、TYPE S（SPEED）のボディをオリジナルの曲面3Dメッシュで再構築しました。
従来のボックス・球体を積み重ねる方法ではなく、縦断形状をつなぐロフト式の連続メッシュを作成しています。

- 細長いノーズと左右に広がるフロントカウル
- 黒い細身のキャノピーと白い一体成形風カウル
- 左右独立したフェンダー、フロントフィン、リアウイング
- 青・赤のレーシングライン、部分的な金属・樹脂表現
- ボディ軽量化の見た目変更にも対応
- TYPE P/Bは従来のデザインを維持。将来別途再構築可能

これまでのパーツ・チューニング・レース・4倍走行テンポ・コースアウト演出・試走操作・SET1〜SET3保存・消耗分析・PWAアイコンは維持しています。
