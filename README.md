# MINI 4WD LAB Ver.0.3.8

- コースアウトまでの前方・外側への勢いは維持

- 滑走・横転・前転・激しい回転を採用。連続して同じパターンは選ばれない
- コースアウト後の走行ログと状態表示で演出の種類を確認可能
- 走行テンポ4倍、チューニング、自由視点、ローラー位置、スマホ横画面、全画面、Wake Lock維持
