# MINI 4WD LAB Ver.0.5.5 PWA

## 試走再生コントローラー
- 上段：▶再生／Ⅱ一時停止／■停止
- 中段：コマ戻し／コマ進み／スロー再生（通常4倍→2倍→1倍→0.5倍→4倍）
- 最下段：ガレージへ戻る
- コマ送りは一時停止中、1回につき1/30シミュレーション秒。過去約60シミュレーション秒のフレームを保持します。
- 巻き戻した位置から再開すると以降の履歴を再計算します。
- スロー再生でもシミュレーション秒による計測・消耗量は変わりません。
- コースアウト後の転倒演出は従来どおり再生。コマ送りはコースアウト直前までの走行記録に対応。
- PWAキャッシュは0.5.5へ更新。既存の公式アイコンを変更せず流用。

※ブラウザ実機の視覚動作検証は未実施です。
