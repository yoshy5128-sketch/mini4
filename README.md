# MINI 4WD LAB Ver.0.5.2 PWA

- 3Dガレージ画面の推定性能に「耐久」を追加。電池容量・電圧降下特性、モーター発熱と寿命、タイヤの特性を反映した相対値です。
- 右ペインの「マシン総合性能（相対値）」および常設グラフを削除しました。
- 左の推定性能直下にグラフ表示を統合。電池選択中は電池3タイプの残量曲線、モーター選択中は温度・寿命曲線を表示。他のカテゴリーではグラフを非表示。
- スマホ横画面ではパネルと文字・グラフをさらに縮小。狭い画面では左パネル内をスクロールできます。
- 走行モデル・周回分析・キャッシュ更新方式・PWAアイコンは前版を維持。
- Service Workerのバージョンを0.5.2へ更新し、キャッシュの入れ替え対象としました。

ブラウザ実機での表示検証は未実施です。
