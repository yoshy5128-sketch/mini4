# MINI 4WD LAB Ver.0.4.1

Ver.0.4.0をベースにした操作改善版です。

- **NormalSET**: ガレージの「02 / パーツセッティング」見出しの右側に追加。現在のベースマシンを保持したまま、モーター・ギヤ・タイヤ・ローラー・ダンパー・ブレーキと詳細調整をすべて標準設定へ戻します。保存済み設定も更新されます。記録は削除しません。
- **コース切替**: 上部「テスト走行」→右フレーム上部「テストコース選択」から平面オーバルと立体テクニカルを切り替えられます。
- 従来の4倍走行テンポ、コースアウト演出、路面表示、スマホ横画面、フルスクリーン、Wake Lockは維持。

Three.jsはCDNから読み込むため、インターネット接続とHTTP(S)サーバーが必要です。
