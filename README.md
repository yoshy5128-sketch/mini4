# MINI 4WD LAB Ver.0.3.5

Ver.0.3.4 をベースに以下を変更しました。

- コースアウト演出の前進方向を、実際のコース中心線の接線から計算。従来のZ座標符号の誤りを修正。
- 進行方向の慣性を保ち、コースの外側へ斜めに飛び出す演出に変更。大きな方向転換は発生させません。
- 前後ローラーを同一の中央基準の取り付けユニットで構築し、左右を厳密に対称に配置。後部のステー補強・支柱も同じ基準に修正。
- 4倍テンポ、約110mオーバル、スマホ横画面の2ペイン、全画面、Wake Lock、単一路面を維持。

※ 走行物理のチューニング数値は変更していません。実機ブラウザでの描画検証は未実施です。
